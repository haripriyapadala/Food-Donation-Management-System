
#  Food Donation Management System

## About the Project

The **Food Donation Management System** is a Java-based project developed to simplify and organize food donation management. It allows users to add food donation details and view the available donations through a simple and user-friendly interface.

This project aims to encourage food sharing, reduce food wastage, and promote efficient management of surplus food.

---

##  Objectives

- To reduce food wastage by encouraging food donations.
- To provide a simple platform for managing food donation details.
- To allow users to add food donation records.
- To view available food donations in an organized manner.
- To promote food sharing and social responsibility.

---

##  Features

-  Add Food Donations
-  View Food Donations
-  Maintain donation details
-  Simple and user-friendly interface
-  Promote food sharing and reduce food waste

---

##  Technologies Used

- **Programming Language:** Java
- **User Interface:** Java GUI
- **Development Environment:** Java-supported IDE
